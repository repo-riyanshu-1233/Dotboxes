🔲 Dots & Boxes

A modern web-based Dots & Boxes game featuring AI Mode, Pass & Play, and real-time online multiplayer gameplay.

Live demo web - https://dotboxes.onrender.com

✨ Features

- 🤖 AI Mode — Play against an AI opponent.
- 👥 Pass & Play — Play with friends on the same device.
- 🌐 Online Multiplayer — Play with other players remotely.
- 🏠 Create Room — Create a private multiplayer game room.
- 🔑 Random Room Code — Generate a unique code for each game session.
- 🔗 Join Room — Join an existing game using a room code.
- ⚡ Real-Time Gameplay — Moves are synchronized between online players.
- 🔲 Box Completion — Complete boxes by connecting dots.
- 🏆 Score Tracking — Automatically keeps track of completed boxes.
- 🔄 Play Again — Start another match after the game ends.
- 📱 Responsive Design — Play comfortably on desktop and mobile devices.

🎮 Game Modes

🤖 AI Mode

Play Dots & Boxes against a computer-controlled opponent.

The AI automatically takes its turns, allowing you to play a single-player match.

👥 Pass & Play

Play with another player on the same device.

Players take turns drawing lines and trying to complete boxes.

Player 1 → Player 2 → Player 1 → Player 2

🕹️ How to Play

The objective is to complete more boxes than your opponent.

1. Select two adjacent dots to draw a line.
2. Continue connecting dots to create boxes.
3. Completing the fourth side of a box claims that box.
4. The player who completes a box gets the point.
5. Continue until all possible boxes are completed.
6. The player with the highest score wins.

🏠 Create a Room

1. Select Online Multiplayer.
2. Create a room.
3. A random room code is generated.
4. Share the code with your opponent.
5. Your opponent joins the room.
6. Start the match.

🔗 Join a Room

1. Select Online Multiplayer.
2. Enter the room code.
3. Join the room.
4. Wait for the connection.
5. Start playing.

🏆 Scoring

Every completed box gives the player one point.

Completed Box = +1 Point

The player with the most completed boxes at the end of the match wins.
